# Personal Portfolio Website

A modern and responsive Personal Portfolio Website developed using **Flask, HTML, CSS, JavaScript and MySQL**.

---

## Features

- Responsive Portfolio Design
- Hero Section
- About Me Section
- Skills Section
- Projects Section
- Contact Form
- MySQL Database Integration
- Admin Dashboard
- Resume Download
- GitHub & LinkedIn Links

---

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- MySQL
- Git
- GitHub

## How to Run

### 1. Clone Repository

```bash
git clone https://github.com/yatharth10-coder/PersonalPortfolio.git
```

### 2. Install Requirements

```bash
pip install -r requirements.txt
```

### 3. Import Database

Import **database.sql** into MySQL.

### 4. Run Application

```bash
python app.py
```

### 5. Open Browser

```
http://127.0.0.1:5000
```
